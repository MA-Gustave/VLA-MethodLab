# Integrated RVV-VLA Lab Studio

The Studio UI is now part of **RVV-VLA-Lab**, not a separate repository.
Start from Lab root with `START_STUDIO.ps1`. The Python interpreter and venv
are shared with `START_HERE.ps1`, while local SSH settings live only in
`orchestrator/.env` (generated by `python tools/rvvlab.py setup`).

Test Runner campaigns 81–87 are manually initiated. Each `*.test.json` pins
a `*_worker.py` SHA256. The `experiments/workers/` folder at the Lab root
contains byte-identical copies used by the CLI.

GUI includes SSH console, manually launched Test Runner, result synchronization,
reporting and remote storage management. It does not start native experiments
unprompted or provision remote servers.

Former standalone `RVV-VLA-Studio` is obsolete.

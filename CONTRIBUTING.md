# Contributing to VLA MethodLab

VLA MethodLab is a separately maintained research workspace, not a submission channel to the simdjson project.

- Check and document the origin, earlier publication, contributor permissions and licences of every added file or source range.
- Do not copy the externally attached `engine/` directory into the MethodLab Git history.
- Maintain the original validity gates, reproducibility records and benchmark baselines; do not silently rewrite historical results.
- Seek an explicit written agreement on the licence for a *new* contribution **before** adding it. A pull request does not automatically grant exclusive rights.
- Do not submit a proposed Covered Addition to another software project for incorporation without written rightsholder authorization, unless an existing grant permits it.
- AI-assisted changes require human review and traceability; compiler success alone is not complete correctness assurance.

See `LICENSE`, `LICENSE-ORIGINAL-ADDITIONS.md` and `PROVENANCE-ADDITIONS.md`.

# Contributions — RVV-VLA Lab

This is an **independent experimental project**, not a contribution, support or merge channel for the original simdjson maintainers. Please do not forward Lab code for incorporation into other projects on the assumption that publication grants such permission.

## Permissions and code provenance

- Before proposing changes, identify **each** touched source file and whether it contains original simdjson or other third-party material.
- Do not remove original copyright, patent, trademark, attribution notices, or applicable Apache-2.0/MIT/third-party licence texts.
- Do not introduce material under incompatible terms or claim exclusive rights over inherited parts.
- External submissions require separate agreement on authorship, licence, AI-generated material and third-party rights **before** incorporation; a pull request, issue, email or patch must not be presumed to grant an exclusive licence to the Lab.
- Only a genuinely new original addition expressly and specifically registered in [`PROVENANCE-ADDITIONS.md`](PROVENANCE-ADDITIONS.md) can be considered for [`LICENSE-ORIGINAL-ADDITIONS.md`](LICENSE-ORIGINAL-ADDITIONS.md), subject to earlier grants and platform terms.

## No upstream submission

Covered Additions are expressly **Not a Contribution** for the purposes of unsolicited incorporation into the original simdjson project. This project does not seek upstream review, maintenance, debugging or adoption. This statement does not limit anyone's rights to the original simdjson code or to an independently written implementation.

Security issues specific to this Lab should be handled through its own maintainer, not automatically assigned to upstream maintainers. Research claims must cite the test configuration, original corpus, baseline and limitations.
